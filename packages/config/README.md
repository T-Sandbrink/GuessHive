# @guesshive/config

Shared tooling configuration for the GuessHive monorepo.

| Export                                 | Use                                           |
| -------------------------------------- | --------------------------------------------- |
| `@guesshive/config/tsconfig.base.json` | `"extends"` in each package's `tsconfig.json` |
| `@guesshive/config/eslint`             | spread into a package's `eslint.config.js`    |
| `@guesshive/config/prettier`           | spread into a package's `prettier.config.js`  |
